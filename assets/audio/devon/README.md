# Devon boss music

The active game score is `theme-rock.wav`, generated by ElevenLabs Music
(`music_v2_5`), not the earlier local synthesizer. The original provider output is
`elevenlabs-original.mp3`; `elevenlabs-composition.json` retains the exact three
24-second section plan: riff attack, heavy escalation, solo and turnaround.

`harness/generate-devon-music.py` performs an explicit ElevenLabs generation using
the configured account. `harness/prepare-devon-music-loop.py` prepares the runtime
wave file with a 1.5-second tail/head blend and peak limiting. Measured durations,
provider and processing parameters are recorded in `theme-rock.json`.

The rejected synthesized draft and its generator were removed during project cleanup.
The audio director selects `theme-devon` only for stage 4 and routes it through the
normal music volume bus. Other arenas retain their existing music.
