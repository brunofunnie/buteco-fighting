# Online selection flow

Execute inline. The room only connects players. Host starts character selection; each player controls their own live, shared selection and confirms. Both then enter the existing arena screen, where only the host controls selection and starts the loading/versus/fight sequence. Results automatically return both clients to their existing room.

Move nickname entry to a themed creation dialog, auto-identify first-time challengers, load rankings on opening multiplayer with client throttling and server caching, and show server-measured RTT with labeled colored signal bars. Validate server permissions/state transitions, stale loading, same-room return, ping challenge validation, responsive UI and offline regressions, then review and deploy.
